# 本地经验库（experience/）

> **这个目录是你个人的，不属于技能包。**
> 它不进 git、不进 `release-*` 发布快照、不随技能分发；重装或覆盖升级技能前请先备份本目录。

## 这里放什么

放**跨任务、可复用、可判定**的经验条目——"以后再遇到这种情形该怎么做"，格式与门槛见 `references/13-experience.md`。

不放：公文正文、来文原文、密级材料、个人身份信息、具体单位数据、一次性偏好。

## 怎么写

1. 按 `references/13-experience.md` 的「入库四问」筛一遍，四问全"是"才写（首次出现即写，不必等复现）。
2. 每个条目一个文件：`E-NNN-主题.md`（三位流水号，主题用短语，如 `E-001-请示结语误用请批示.md`）。
3. 同步在 `INDEX.md` 加一行索引。
4. 同一模式再次出现时，改原条目的「复现次数」，不新建文件。

## 现状

初始为空。第一次做完复盘后再生成 `E-001`，`INDEX.md` 保持空表即可。
