# 记忆梦境：经验提炼与长期沉淀

> 何时读：每次 S6 之前；用户说「复盘」「总结一下这次」「以后别再犯」；同一类问题第二次出现时。
> 读完产出：本次复盘结论（提炼哪条 / 为何不提炼）与经验库条目。
> 本文件是**协议**。实际条目写在 `experience/`（本地经验库，不随包分发、不入库、不进发布快照）。

## 一、记忆梦境是什么

写完不立刻收工。回看"草稿 → 终稿"的全部改动，只问三句：

1. 这次哪里改得最多？为什么改？
2. 这个原因能不能**脱离本篇**成立？
3. 能成立的，用一句话写成"什么情况下该怎么做"。

梦境只沉淀**可复用的判断**，不沉淀"这次写了什么"。它的产出是一条可判定的规则，不是一篇心得。

## 二、四个入口（满足任一即做）

- 每次公文交付完成后（S6 之前，作为固定动作）
- 用户说了纠正性的话：「不对」「应该……」「以后别……」
- 同一类问题第二次出现
- 用户明确说「复盘」

## 三、入库四问（全部答"是"才可入库）

> **v0.8.0 改判据**：旧版第二问要求「出现过两次以上**或**与《条例》／GB/T 9704 条文一致」，
> 等于规定"第一次出现、且国标没覆盖的经验永远不许入库"，与"记录经验"的目的直接相反。
> 现在把"复现次数"从**入库门槛**降为**置信度字段**：首次即可入库，复现多了再升置信度。

| 问 | 判据 |
|---|---|
| **可脱离** | 去掉本篇的单位、数据、事项后仍成立？换成同类公文另一篇还适用？ |
| **可判定** | 能用一句话判断"犯了没犯"？还是只能说"感觉好一点"？ |
| **有出处** | 能指到成稿前后对照、用户原话或条款号？ |
| **非抄书** | 不是 `references/` 里已经写着的规则？（抄书不算经验，那条直接指向原文即可） |

- 四问全过 → 入库，`复现次数：1（首次 YYYY-MM-DD）`，置信度按后表定。
- **任一问为"否"** → 不入库，但必须在《注意事项》写明**是哪一问、缺什么、补什么就能入库**（例：「可判定未过：只能判断"感觉更顺"，缺反例 ⇒ 下次给一句反例即可入库」）。只写"无可沉淀"视为未做梦境。
- 一次交付**至少产出 1 条候选**（可标低置信度）；确实零候选时，须逐条说明为何四条改动都不构成判断（不是"这次没什么可记的"）。

## 四、拒收清单（不必多想，直接不收）

- 具体数字、单位名、人名、金额、时限
- 一次性偏好（"这次领导喜欢短一点"）
- 涉密信息、未公开政策、个人身份信息
- 无判据的"感觉"（"这样更有味道"）
- 已能在 `references/` 查到的规则——那是抄书，不是经验

## 五、条目格式（`experience/E-NNN-主题.md`）

正文不超过 15 行，固定七项：

```
触发场景：<什么文种/什么位置/什么情形>
错误模式：<写成什么样算错，附一句反例>
正确做法：<改成什么样，附一句正例>
判　据：<怎么一眼判出犯了没犯>
出　处：<用户原话 / 草稿与终稿对照 / 条款号>
复现次数：N（首次 YYYY-MM-DD）
置信度：高 / 中 / 低
```

同时在 `experience/INDEX.md` 加一行索引（编号｜主题｜触发场景｜置信度｜复现次数｜日期）。

## 六、晋升与淘汰

| 状态 | 条件 | 动作 |
|---|---|---|
| 低 | 首次出现、判据尚未被复现验证 | 入库，复现次数记 1；下次同类任务优先回看 |
| 中 | 首次出现但判据直接来自条款、用户原话或明确对照 | 入库，复现次数记 1 |
| 高 | 复现 ≥2 次且判据稳定 | 同模式合并为一条，旧条目标 `superseded_by`，不物理删除 |
| 提请入规 | 复现 ≥3 次且与国标/条例一致 | **提请**用户同意后写入 `references/`；不得自行修改硬规则 |
| 待复核 | 12 个月未复现 | 标注，使用前先核实现行规范 |
| 已驳回 | 用户明确不同意入规 | 条目**保留**在 experience/，置信度改记「高（未入规）」，INDEX 主题后标「（已提请·已驳回 YYYY-MM-DD）」，12 个月内不得重复提请 |
| 已废止 | 条款变更或与本包规则冲突 | 标"已废止·日期"并保留，供追溯 |

## 七、三条边界

1. **只写做法与判据**：不写公文正文、不写来文原文、不写密级材料、不写个人身份信息。
2. **不得覆盖硬规则**：经验与 `07-review.md`／`05-format.md` 冲突时，一律以 references 为准，经验条目降级为"观察"。
3. **不入库不分发**：`experience/` 是本地资产，不进 git、不进 `release-*` 快照、不随包分发；技能重装前须先备份该目录。

**写入不需用户同意（v0.8.0）**：`experience/` 是本地经验库、可随时删除、不进任何分发物，因此四问一过就直接写，不再"展示候选、等确认"。**S6 记忆文件（`errors.md`／`style.md`）仍须用户确认后写入**——两者性质不同，不要一起省。

## 八、与 S6 记忆沉淀的分工

| | S6 记忆（`errors.md`／`style.md`） | 记忆梦境（`experience/`） |
|---|---|---|
| 范围 | 本任务的错误与风格偏好 | 跨任务、可复用的判断 |
| 位置 | 工作区 `.gongwen/memory/` | 技能内 `experience/`（唯一允许写的技能内目录） |
| 门槛 | 有来源即可（写入前须用户确认） | 必须过"入库四问"（写入不需用户确认） |
| 用途 | 下次同类任务提高警觉 | 长期抬高能力基线 |

两者不重复：S6 收"这次错了什么"，梦境收"以后怎么不再错"。
