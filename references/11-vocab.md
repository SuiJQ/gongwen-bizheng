# 机关动宾搭配与六字对（按需查）

> 何时读：S3 落笔时取搭配；起草小标题或概括句时；S4-G6 判断某段是否空转或修辞过密。
> 读完产出：可用搭配清单、空转与修辞过密命中项。
> 本文件是**取词资源，不是规范**。语言底线见 `06-language.md` 第二节，门禁权威见 `07-review.md`；冲突时以后两者为准。

## 使用纪律

1. 只解决"该处该有动作词／该有筋骨"，不解决"该写什么"。事实、主责、时限仍须来自材料。
2. 四层位置不可串用：任务句不用比喻，标题句不堆动作，号召句不进正文。
3. 任一条目脱离"兑现条件"即降级为套话，按 `06-language.md` 第二节处理。

|---|---|

## 二、概括句六字对（小标题、段首用，8 条可用 + 4 条受限）

| 六字对 | 兑现条件 |
|---|---|
| 厚植发展优势 | 有比较优势事实 |
| 补齐发展短板 | 有短板清单 |
| 做强做优做大×× | 有对象与指标 |
| 打通最后一公里 | 有具体事项与承接主体 |
| 试点先行、逐步推开 | 有试点范围与时序 |
| 抬高工作标杆 | 有对标对象 |
| 拧紧责任链条 | 挂环节与责任人 |
| 挂图作战、对表推进 | 有节点表 |

**受限条目**——不满足右列条件即按 `06-language.md` 禁用项处理（无实指判断／口号堆砌／强行升华），**不计入可用**：

| 条目 | 唯一可用条件 |
|---|---|
| 抓重点、破难点、通堵点 | 三项各自落到具体事项；缺一即判"排比堆砌" |
| 见行见效、落实落地 | 前一段已给事实与数据，此处只做 12 字以内总评；不得作段首独立句 |
| 强信心、稳预期、促发展 | 仅总结或讲话开头一句带过，同篇不超过 1 次 |
| 聚合力、破难题、开新局 | 仅讲话结尾，全篇不超过 1 处；正文出现即判"口号堆砌" |

## 四、号召句（仅讲话结尾、动员段，4 条）

| 句式 | 约束 |
|---|---|
| 以××促××、以××带×× | 全篇不超过 2 处，须紧接具体任务 |
| 拧成一股绳、下好一盘棋 | 全篇不超过 1 处 |
| 一级抓一级、层层抓落实 | 须绑定责任链条 |
| 起步即冲刺、开局即决战 | 仅年度／专项动员，不得进正文 |

## 五、禁用与反例

**比喻词根密集群**（判定口径见第六节判据 2，按喻体词而非"之X"句式计数）：

| 反例 | 问题 | 改法 |
|---|---|---|
| 打牢从政之基、补足精神之钙、高扬信念之帆、把牢思想之舵 | 同一比喻系统堆叠 4 个 | 保留 1 处，其余落为具体任务 |
| 校准思想之标、绷紧纪律之弦、紧握法纪戒尺、挺起精神脊梁 | 同上 | 改为"依据××条开展××" |

**领域错位，本技能不收**：打造拳头产品、追溯报人报事、争做理论达人、当好提灯使者（宣传／报社／理论语境）。
**语境冲突**：创造金山银山（脱离"绿水青山就是金山银山"即歧义）。

## 六、两条判据（供 G6）

1. **空转**：同一段出现 3 个以上本文件条目（含受限条目），且**本段与下一段**均无主责单位、时限、数据 → 按 `06-language.md` "排比堆砌"退回改写。主责写在下一句的，不算空转。
2. **修辞过密**：同一段**喻体词**（基、钙、帆、舵、弦、标、脊梁、戒尺、链条、压舱石、引擎、良方、暗礁）出现 3 个以上 → 判"油"，压到 2 个以内。

> 判据 2 的边界：**只认喻体词，不认句式**。"之X""为X""以X"这类结构本身不参与判定——"以规划为引领、以项目为支撑、以考核为抓手"是正常的任务排比，不是比喻；"打牢从政之基/补足精神之钙"之所以算，是因为"基""钙"都在喻体表内。
