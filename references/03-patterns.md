# 文种范式与骨架

> 何时读：S2 生成蓝图、S3 起草时。只读当前文种，不预加载全部。
> 读完产出：该文种的骨架、开头结尾惯用语、语气模态、填写纪律。

## 使用规则

- 范式用于防漏项，不是套话仓库。填内容，不填空话。
- 每节先明确唯一任务；不得为凑结构增加无任务章节。
- 惯用语可按关系与场合调整措辞，但不得改变文种功能。
- 法定文种以《条例》为准；事务材料为长期实践形成的惯例，可调整。
- 骨架节数可增减，功能不可缺：法定文种至少具备"缘由—事项—结语"或"情况—分析—要求"。

## 一、通用骨架

```
标题（发文机关 + 事由 + 文种）
主送机关（普发性可省）
正文：缘由/依据 → 事项/情况 → 结语/要求
附件说明（如有）
发文机关署名
成文日期
```

## 二、15 个法定文种

### 1. 决议

- 适用：会议讨论通过的重大决策事项。**《条例》未限定会议是否为常设**——凡经会议集体讨论通过的重大决策事项均可作决议，人大常委会等常设机关的会议亦可；会议通过本身不是充分条件，决定也可经会议通过。
- 骨架：标题 → 会议概况（时间、会议名称、议题）→ 决议事项 → 号召或要求。
- 惯用语："会议听取和审议了……""会议决定……""会议号召……"。
- 语气：庄重、决断，体现集体意志。
- 易错：未经会议讨论通过；与决定混用；夹带未议定内容。

### 2. 决定

- 适用：重要事项决策部署、奖惩有关单位和人员、变更或撤销下级机关不适当的决定事项。决定可由常设机关作出，也可以经会议讨论通过，文种仍是决定。
- 骨架：标题 → 缘由与依据 → 决定事项（分条）→ 执行要求。
- 惯用语："经研究决定……""现决定……"。
- 语气：权威、明确、可执行。
- 易错：奖惩决定缺事实与依据；决定事项无责任主体；与决议混用。

### 3. 命令（令）

- 适用：公布行政法规和规章、宣布**施行**重大强制性措施、批准授予和晋升衔级、嘉奖。
- 骨架：令号 → 正文（发布依据 + 命令事项）→ 签发人职务、签名章、成文日期。
- 语气：庄重、简短、无商量余地。
- 易错：非法定授权机关使用；用于一般工作部署；正文冗长。

### 4. 公报

- 适用：公布重要决定或者重大事项。
- 骨架：标题 → 会议或事件概况 → 决定或事项 → 发布语。
- 语气：正式、公开、概括。
- 易错：与公告混用；把一般事项写成公报。

### 5. 公告

- 适用：向国内外宣布重要事项或者法定事项。
- 骨架：标题 → 依据 → 公告事项 → 结语。
- 惯用语："特此公告。"
- 语气：准确、简洁、无歧义。
- 易错：一般事务滥用公告；发布范围与事项重要性不匹配。

### 6. 通告

- 适用：在一定范围内公布应当遵守或者周知的事项。
- 骨架：标题 → 依据或目的 → 应遵守、周知事项 → 执行要求或结语。
- 惯用语："特此通告。"
- 语气：告知性强，要求明确。
- 易错：与公告、通知混用；适用范围不清。

### 7. 意见

- 适用：对重要问题提出见解和处理办法。
- 骨架：标题 → 缘由与依据 → 具体意见（见解 + 办法，分条）→ 执行要求或批转请求。
- 方向适配：下行意见提要求；上行意见按请示性公文的程序和要求办理（不是报告），涉及其他部门职权先协商，上级机关应作出处理或答复；平行意见供对方参考。
- 语气：见解鲜明、办法可行。
- 易错：只提原则不给办法；行文方向不明；与通知混用。

### 8. 通知

- 类型：指示部署、批转转发、任免、会议、告知。
- 骨架：标题 → 主送 → 缘由（"为……""根据……，现就……通知如下"）→ 事项（分条）→ 执行要求。
- 惯用语：指令性用"请认真贯彻执行""请遵照执行"；告知性用"特此通知"。
- 语气：明确、肯定、可操作。
- 易错：用通知表彰；事项空泛、无责任与时限；与通报混用。

### 9. 通报

- 类型：表彰、批评、情况。
- 骨架：标题 → 主送 → 事由（事迹、错误事实、重要情况）→ 分析评价或原因教训 → 决定或处理意见 → 希望要求。
- 语气：表彰庄重褒扬，批评严肃审慎，情况客观准确。
- 易错：事实不清、定性不准；用通报部署工作；表彰缺名单或事实。

### 10. 报告

- 类型：工作报告、情况报告、答复报告、报送报告。
- 骨架：标题 → 主送 → 缘由或概况 → 主体（情况、做法、成效、问题、打算）→ 结语。
- 惯用语："现将……报告如下""特此报告""以上报告，请审阅"。
- 硬规则：不得夹带请示事项；结尾不得用"请批示""请批复"。
- 易错：报告与请示混用；只报喜不报忧；数据无来源。

### 11. 请示

- 骨架：标题 → 单一主送 → 缘由（情况 + 依据 + 必要性）→ 请求事项（具体，附倾向性意见）→ 结语。
- 惯用语："妥否，请批示""当否，请批复""以上请示，请予批复"。
- 法定硬规则：一文一事；原则上主送一个上级；上行文标注签发人。
- 测算口径：请款类请示须给可核测算，不得只写总额。常用三类：①储备定额 × 单价 × 缺口数量；②上年同期实际发生额 × 增长系数；③险情频次 × 单次处置成本。参数缺失时列参数占位（如 `【待补：储备定额】`），不得自拟数字。
- 惯例要求：事前行文，不得先斩后奏；结语用句号。
- 语气：尊重、期请，结语用句号。
- 易错：先斩后奏；多头主送；一份请示多事项；与报告合用。

### 12. 批复

- 骨架：标题 → 主送（请示机关）→ 引叙来文（"你×《关于……的请示》（×〔2026〕×号）收悉"）→ 批复意见（同意/不同意/部分同意 + 理由 + 要求）→ 结语。
- 惯用语："经研究，现批复如下""特此批复"。
- 语气：明确、肯定、权威。
- 易错：无请示先批复；答非所问；擅自扩大批复范围。

### 13. 议案

- 适用：各级政府按法律程序向同级人大或常委会提请审议事项。
- 骨架：标题 → 主送（人大或常委会）→ 案由 → 方案或说明 → 提请审议。
- 语气：庄重、程序规范。
- 易错：非政府机关使用；缺法定程序；说明不充分。

### 14. 函

- 类型：商洽、询问、请批、答复（复函）、告知。
- 骨架：标题 → 主送 → 缘由 → 事项 → 结语（可附联系人）。
- 惯用语：告知"特此函达"；询问商洽"特此函询""盼复"；请批"请予支持并盼复"；复函"特此函复""此复"。
- 语气：平等、礼貌、协商；用"贵单位""贵局"。
- 易错：对有隶属关系的上级用函；平行文用"你单位"不够得体（宜用"贵单位"）；复函不引来文。

### 15. 纪要

- 骨架：纪要标志 → 会议概况（时间、地点、主持人、出席、列席、议题）→ 会议认为 → 会议决定（分条，明确责任与时限）→ 会议要求 → 出席、请假、列席名单。
- 语气：客观概括，统一用"会议认为""会议决定""会议要求"。
- 易错：写成会议记录；夹带个人意见；议定事项无责任主体与时限；格式误用通知。

## 三、8 类高频事务材料

### 1. 讲话致辞

- 类型：部署动员、形势报告、交流发言、开闭幕致辞。
- 骨架：称呼 → 开场（场合、背景）→ 主体（形势与任务、观点与论据）→ 结尾（号召、祝愿）。
- 要点：口语化但不随意；一段一个意思；有具体事例；避免通篇排比与口号。
- 层级与序号一致：说“我讲三点意见”就写三点；责任、纪律等要求纳入三点之内或另设一级，不得悬空另列。
- 易错：居高临下、空话连篇；数据不实；称呼与场合不符。

### 2. 总结

- 骨架：标题 → 导语（背景、总体评价）→ 主要做法与成效（分条）→ 存在问题 → 下步打算。
- 要点：数据支撑；做法可复制；问题不回避；避免流水账。
- 易错：只列工作不提炼；成绩夸大；问题笼统。

### 3. 述职

- 骨架：标题 → 导语（职责、年度目标）→ 履职情况（分条，数据与事例）→ 不足 → 改进措施。
- 要点：以职责为纲；不揽功不诿过；数据与事例对应。
- 易错：写成单位总结；只讲成绩不讲不足。

### 4. 方案 / 规划

- 骨架：标题 → 指导思想与目标 → 重点任务（分条，责任与时限）→ 保障措施 → 附件。
- 要点：目标可衡量；任务有主责与时限；措施可执行。
- 易错：目标空泛；任务无责任主体；措施与任务脱节。

### 5. 调研报告

- 骨架：标题 → 调研概况 → 现状与问题（数据、案例）→ 原因分析 → 对策建议。
- 要点：问题导向；数据真实；建议对应问题。
- 易错：材料堆砌无观点；问题与建议不对应；数据无来源。

### 6. 经验材料

- 骨架：标题 → 背景或由头 → 做法（分条，每条一个机制）→ 成效（数据）→ 启示。
- 要点：做法具体可学；每条有机制而非口号；成效有数据。
- 易错：自我表扬；做法空泛；只讲结果不讲怎么做的。

### 7. 汇报

- 骨架：标题 → 导语（依据、总体情况）→ 工作进展 → 问题与困难 → 下步安排或请求事项。
- 要点：按上级关注点组织；数据准确；请求事项单列。
- 易错：与报告混用；请求事项夹在情况中；无下步安排。

### 8. 会议材料

- 类型：会议纪要（法定）、议题说明（首批）；主持词、议程为长尾，不承诺完整范式。
- 骨架（议题说明）：背景 → 议题内容 → 需会议决定事项 → 建议。
- 要点：紧扣议题；决定事项清晰；不夹带无关内容。
- 易错：议题说明写成工作汇报；决定事项模糊。

## 四、骨架选用纪律

- 只取当前文种骨架，不因"参考"混用其他文种结构。
- 骨架必须覆盖三类功能：缘由、事项、结语（事务材料为背景、做法、成效或建议）。
- 每节标注唯一任务，并与蓝图一致。
- 法定文种标题用"发文机关 + 事由 + 文种"；事务材料标题可灵活，但必须准确概括内容。

## 五、高频错误速查

| 错误 | 正确做法 |
|---|---|
| 请示报告合用 | 按是否需要批复拆分 |
| 报告结尾"请批示" | 报告用"特此报告" |
| 多头主送 | 单一主送，其他抄送 |
| 用通知表彰 | 用通报 |
| 用通报部署 | 用通知 |
| 公告发布一般事务 | 改通告或通知 |
| 纪要写成会议记录 | 概括议定事项，明确责任时限 |
| 模板套话成篇 | 每节填具体内容与数据 |
| 讲话通篇排比 | 一段一个意思，举例支撑 |
| 方案无责任时限 | 任务附表：主责、时限、成果 |
