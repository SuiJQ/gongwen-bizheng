# 文种、场景与任务路由

> 何时读：S0 判定文种、场景与任务类型时；G1 需要完整判定链时。
> 读完产出：任务卡中的文种判定链、场景定位、任务类型分支。

## 一、三步判定法

顺序固定，不可颠倒：

1. **行文目的**：请求批准、汇报情况、部署工作、商洽事项、答复来文、记载议定、向社会公布。先确定"要收文方做什么"。
2. **行文关系**：隶属（上行/下行）、不相隶属（平行）、面向社会（公布）、会议通行（纪要）。
3. **法定适用范围**：对照 15 个法定文种的定义，只选唯一匹配项。

判定链必须写出来，例如：

`目的=请求批准 → 关系=下级机关对上级机关 → 适用=请示 → 文种=请示`

没有写出判定链，等于没有判定。

## 二、15 个法定文种速查

> 方向统一按"上行/下行/平行/公布/通行（纪要）"标注。"会议发布""政府→人大"不是独立行文方向，分别并入"公布/下行"与"特别程序"。

| 文种 | 适用范围（节引《条例》第八条，以原文为准） | 方向 | 模态 | 高频误用 |
|---|---|---|---|---|
| 决议 | 会议讨论通过的重大决策事项 | 下行/公布（会议通过后发布） | 记载+指令 | 与决定混用 |
| 决定 | 对重要事项作出决策和部署，奖惩有关单位和人员，变更或者撤销下级机关不适当的决定事项 | 下行 | 指令 | 与决议混用 |
| 命令（令） | 公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员 | 下行 | 指令 | 非授权机关使用 |
| 公报 | 公布重要决定或者重大事项 | 公布 | 告知 | 与公告混用 |
| 公告 | 向国内外宣布重要事项或者法定事项 | 公布 | 告知 | 一般事项滥用公告 |
| 通告 | 在一定范围内公布应当遵守或者周知的事项 | 公布 | 告知 | 与公告、通知混用 |
| 意见 | 对重要问题提出见解和处理办法 | 上行/下行/平行 | 视方向 | 与通知混用 |
| 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文 | 下行为主（兼及需周知的有关单位） | 指令/告知（视类型） | 用通知表彰 |
| 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 | 下行 | 告知+评价 | 用通报部署工作 |
| 报告 | 向上级机关汇报工作、反映情况，回复上级机关的询问 | 上行 | 陈述 | 夹带请示事项 |
| 请示 | 向上级机关请求指示、批准 | 上行 | 请求 | 与报告合用 |
| 批复 | 答复下级机关请示事项 | 下行 | 指令 | 与复函混用 |
| 议案 | 各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项 | 特别程序（政府→同级人大/常委会，非隶属行文） | 提请 | 非政府机关使用 |
| 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项 | 平行 | 协商/请求/答复/告知（视类型） | 对有隶属关系的上级用函 |
| 纪要 | 记载会议主要情况和议定事项 | 通行（可上行/下行/平行；一般不标主送，采用分送） | 记载 | 写成会议记录 |

## 三、易混文种判别

| 对比 | 判别问题 | 结论 |
|---|---|---|
| 请示 / 报告 | 是否需要上级批复？ | 需要→请示；不需要→报告 |
| 请示 / 函 | 双方有隶属关系吗？ | 有→请示；无→函（请批函） |
| 通知 / 通报 | 是部署执行，还是表彰批评、传达情况？ | 部署→通知；表彰批评/情况→通报 |
| 公告 / 通告 | 面向国内外、事项重要或法定，还是一定范围内应遵守周知？ | 前者→公告；后者→通告 |
| 决定 / 决议 | ①是否由会议集体讨论通过？②是否属重大决策事项？ | 二者同时成立→决议（《条例》未限定非常设会议，常设机关会议通过亦可）；由机关直接作出、不经会议表决→决定 |
| 纪要 / 会议记录 | 是概括议定事项，还是原始发言记录？ | 议定事项→纪要；原始记录→记录（非公文） |
| 批复 / 复函 | 来文单位是下级（隶属）还是不相隶属？ | 下级→批复；不相隶属→复函 |
| 命令 / 决定 | 发文机关是否有法定命令权，事项是否属命令范围？ | 是→命令；一般决策部署→决定 |
| 意见 / 通知 | 是提出见解办法，还是具体部署执行？ | 见解办法→意见；具体部署→通知 |
| 规章公布 | 是否为行政法规、规章？ | 用命令（令）公布 |
| 非规章材料 | 是否为规定、办法、总结、计划、要点、说明、方案等非规章材料？ | 不直接行文；用印发/转发通知，原文作附件 |

## 四、场景路由（场景表）

| 场景大类 | 具体场景 | 落点 |
|---|---|---|
| 报告与上报信息 | 部门工作报告、落实指示报告、问题调研报告、整改报告、学习心得（非首批）、项目申请 | 报告 / 调研报告 / 方案；项目申请按是否需批准转请示/请批函；学习心得非首批，按事务材料处理并说明 |
| 讲话致辞 | 形势报告、政策解读、人物评价、事件评价、交流发言、就职演讲、集会演讲、开闭幕致辞 | 讲话致辞（事务材料） |
| 会务文书 | 议案和建议、提案建议答复、会议纪要 | 议案 / 函 / 纪要 |
| 计划与方案 | 规划、计划、行动计划、工作方案 | 方案 / 规划（事务材料） |
| 总结与述职 | 年度/半年/季度总结、述职报告、政策落实总结、部门工作总结 | 总结 / 述职（事务材料） |
| 许可与批复 | 批复 | 批复 |
| 书信 | 倡议书、决心书、感谢信 | 事务材料（长尾，首批不承诺） |
| 通报 | 表彰、批评、情况通报 | 通报 |
| 汇报 | 答复上级批示、项目汇报、阶段工作汇报、主题工作汇报 | 汇报（事务材料，按关系可套报告/函） |
| 调研 | 实地考察调研、意见汇总调研 | 调研报告（事务材料） |
| 经验材料 | 做法提炼、交流材料 | 经验材料（事务材料） |
| 会议材料 | 议题说明、主持词、议程 | 议题说明为首批；主持词、议程为长尾，不承诺完整范式 |

裁剪原则：

- 首批覆盖：15 个法定文种 + 讲话致辞、总结、述职、方案/规划、调研报告、经验材料、汇报、会议材料。
- 长尾（倡议书、决心书、感谢信、主持词等）：不承诺完整范式；需要时用最接近骨架，并在交付时说明"非首批覆盖"。
- 新闻稿、推文、文学创作：不属本技能，明确告知并停止。

## 五、任务类型分支

| 类型 | 判别信号 | 流程差异 | 交付物 |
|---|---|---|---|
| 起草 | "写一份""起草""拟一个" | 走完整 S1–S6 | 净稿 + 清单 + 版式结果 |
| 修改 | "改一下""润色""压缩" | S1 产出诊断表；S2 只列改动点；S3 只改点名处；S5 附修改说明 | 改稿 + 修改说明 |
| 审核 | "审一下""有没有问题""把关" | S1 只确认范围；S2 跳过；S3 不写正文；S4 输出分级意见 | 审核意见（必须改/建议改） |
| 片段补写 | "补一段""加个小标题""写个开头" | S1 只锁上下文与衔接；S3 只写片段；S4 增加衔接检查 | 片段 + 衔接说明 |

判别不清时按"起草"处理，并在任务卡注明假设。

## 六、文种与模态对应

| 模态 | 文种/类型 | 语态要求 |
|---|---|---|
| 指令态 | 决定、批复、命令、下行意见、指示部署类通知 | 明确、可执行、有主责与时限 |
| 请求态 | 请示、请批函 | 尊重、期请、事项具体可批 |
| 陈述态 | 报告 | 客观、如实、不夹带请求 |
| 协商态 | 商洽函、询问函 | 平等、礼貌、就事论事 |
| 答复态 | 复函 | 明确、有据、对应来文 |
| 记载态 | 纪要 | 客观概括、用"会议认为/决定/要求" |
| 告知态 | 公告、通告、公报、情况通报、告知性通知 | 准确、简洁、无歧义 |

模态由文种、类型与行文方向共同决定，不能一文种一模态：意见跨上行/下行/平行；纪要通行；函平行；通报下行；通知以下行为主，兼及需周知的有关单位。

## 七、不要做的事

- 不生造文种，不写"请示报告"。
- 不因用户口语说法直接定文种："给上级写个申请"可能是请示，也可能是请批函，先判关系。
- 不用通知表彰，不用通报部署，不用公告发布一般事务。
- 不把总结、计划、方案当作法定文种直接行文。
- 不把"经会议讨论通过"当作决议的充分条件；决定也可以经会议通过。
- 不把规章用印发通知公布；行政法规、规章用命令（令）。
- 文种无法唯一确定时，提出一个二选一问题；不能提问时按最可能文种推进并在假设清单标注。
