# 行文规则、称谓与政策引用

> 何时读：S1 确定行文关系时；S4-G1/G3 判定时；涉及主送、抄送、称谓、政策引用时。
> 读完产出：行文关系判定、主送抄送方案、政策引用清单。
> G1/G3 的权威清单见 `07-review.md`；本节为快速自检。

## 一、行文关系

| 关系 | 适用对象 | 常用文种 |
|---|---|---|
| 上行 | 有隶属关系的上级机关 | 请示、报告、上行意见 |
| 下行 | 有隶属关系的下级机关 | 通知、决定、批复、通报、命令、下行意见 |
| 平行 | 不相隶属机关 | 函 |
| 公布 | 面向社会 | 公告、通告、公报 |
| 通行 | 纪要（可上行/下行/平行，一般不标主送，采用分送） | 纪要 |

行文关系由**隶属关系与职权范围**共同确定，不按机关级别高低推断。

## 二、总则与越级行文

- 行文应当确有必要，讲求实效，注重针对性和可操作性。
- 行文关系根据隶属关系和职权范围确定。**一般不得越级行文**；特殊情况需要越级行文的，应当**同时抄送被越过的机关**。
- 不得以越级规避直接上级；需要上级及时知情时，优先逐级行文并抄送相关上级。
- 越级请示、越级报告风险较高；除紧急或特殊情形外，采用逐级转报并附倾向性意见。

## 三、上行文规则

1. 原则上主送一个上级机关；根据需要抄送相关上级和同级机关，**不抄送下级机关**。
2. 部门向上级主管部门请示、报告重大事项，应经本级党委、政府同意或授权；属部门职权范围内的事项，直接报送上级主管部门。
3. 转报下级请示，必须提出倾向性意见，**不得原文转报**。
4. **请示一文一事**；**报告等非请示性公文不得夹带请示事项**。
5. 除上级机关负责人直接交办外，不对领导个人行文，不以机关负责人名义向上级报送。
6. 受双重领导的机关向上级行文，必要时抄送另一上级。

## 四、下行文规则

1. 主送受理机关，根据需要抄送相关机关；**重要行文同时抄送发文机关的直接上级**。
2. 党委、政府的办公厅（室）根据本级党委、政府授权，可以向下级党委、政府行文；其他部门和单位**不得向下级党委、政府发布指令性公文，也不得在公文中向下级党委、政府提出指令性要求**。需经政府审批的具体事项，经政府同意后可以由政府职能部门行文，文中须注明**已经**政府同意。
3. 部门可在职权范围内向下级党委、政府的相关部门行文。
4. 涉及多个部门职权的事务，**未协商一致不得向下行文**。
5. 向受双重领导的下级行文，必要时抄送其另一上级。

## 五、联合行文与内设机构

- 同级党政机关、党政机关与其他同级机关**必要时**可以联合行文；**属党委、政府各自职权范围内的工作，不得联合行文**。
- 联合发文由**所有联署机关的负责人会签**，会签齐全后方可印发。
- 党委、政府的部门依据职权可相互行文。
- **部门内设机构除办公厅（室）外，不得对外正式行文。**

## 六、主送与抄送

| 情形 | 主送 | 抄送 |
|---|---|---|
| 上行请示 | 一个主管上级（原则上） | 根据需要抄送相关上级、同级；不抄下级 |
| 上行报告 | 一个上级（原则上） | 根据需要抄送相关上级、同级 |
| 下行通知 | 受理机关 | 根据需要抄送相关机关；重要行文抄直接上级 |
| 平行函 | 对方机关 | 按需 |
| 公布性文件 | 无主送 | 按需 |
| 纪要 | 一般不标主送 | 按分送范围 |

> 表中为默认情形；"原则上/根据需要/必要时"等限定以《条例》原文为准，G1 不得把原则当绝对。

- 主送机关用全称、规范化简称或同类型机关统称。
- 主送过多导致首页不能显示正文时，移至版记。
- 同级机关排序按党、政、军、群惯例；具体以本机关常规为准。

## 七、称谓与口径

| 方向 | 对对方 | 自称 |
|---|---|---|
| 上行 | 上级机关全称或规范简称 | 我单位 / 我委 / 我局 |
| 下行 | 下级全称或统称（如"各区县人民政府"） | 我委 / 我局 |
| 平行 | 贵单位 / 贵局 | 我单位 |

- 同一文内称谓一致；首次出现用全称，需简称时在首次出现处标注"（以下简称××）"。
- 不混用党委、政府口径；按发文主体和事项性质确定。
- 平行文宜用"贵单位""贵局"，避免"你单位"；"你局"不是命令式称谓，但在平行文中不够得体（惯例）。

## 八、政策引用纪律

1. **三段论**：大前提（条款管什么）→ 小前提（本案是否落入）→ 结论（是否适用、适用哪一环节）。
2. **一策一案**：每条政策对应具体举措，禁止只贴文件名。
3. **引用四要素**：文件名称 + 文号（如有）+ 条款 + 原文摘录（≤50 字）。
4. **不得从"未明示禁止"推出"允许"**。
5. **核验写法**：已核用 `[已核·来源：文件+条款]`，未核用 `[未知：待核对原文]`，交付时转 `【待核对原文：…】`；"通行做法"一律归未核。
6. **触发范围**：决策、资金、项目、资源、问责、改革六类事项必须引依据；纯程序性告知可轻量引用。
7. 无原文时只能作线索，不得写成依据；用占位符标明待核。

## 九、事实与数据纪律

- 事实三态：`[已核·来源]`、`[假设·待确认]`、`[未知]`。
- **推定词黑名单**：预计、按惯例、通常、大概、应该是、据了解（无来源）。落在关键事实位即视为未核。
- 数据三态：定值、截至值、待核；**截至值必须带时间**；同一对象的同一属性，全文只在一处声明。
- 定级纪律：事实 → 推演 → 结论；禁止无依据上调（防御性拔高），也禁止无依据压低。
- 时间写具体日期；除确需模糊处理外，不用"近期""日前""若干"。

## 十、G1 自检

- [ ] 文种合法且唯一
- [ ] 行文方向与文种性质、受文关系匹配（纪要按"通行"处理）
- [ ] 主送合规：上行原则上单一主送；下行/平行主送受理机关；公布无主送
- [ ] 抄送合规（上行不抄下级）
- [ ] 请示一文一事
- [ ] 报告等非请示性公文未夹带请示事项
- [ ] 未越级，或已同时抄送被越过机关
- [ ] 未主送领导个人（直接交办除外）
- [ ] 联合行文符合同级、非各自职权要求，联署机关负责人会签齐全
- [ ] 内设机构未对外正式行文

## 十一、G3 自检

- [ ] 六类必引事项已引依据（纯程序性告知可轻量引用）
- [ ] 每条引用有原文摘录与出处
- [ ] 三段论完整，非贴标签
- [ ] 一策一案，政策与举措对应
- [ ] 无"未禁止即允许"式推导
- [ ] 未核项已标注，未冒充已核
