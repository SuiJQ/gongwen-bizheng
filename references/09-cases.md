# 好差对照与边界案例

> 何时读：规则有争议、需要校准判断时；不用于日常预加载。
> 读完产出：判定参照与修改方向。

## 一、好差对照

| 场景 | 差 | 好 | 判定点 |
|---|---|---|---|
| 开头 | 随着经济社会的发展，我单位高度重视…… | 2026年6月1日进入汛期，全市有水库12座、堤防86公里。 | 具体时间与对象，替代万能背景 |
| 结尾 | 让我们携手共进，谱写新时代新篇章！ | 请各区县于6月10日前报送排查台账。 | 收束到事项与时限 |
| 过渡 | 综上所述，不难发现，值得一提的是…… | （直接进入下一事项，或用一个事实承接） | 删除无信息过渡 |
| 数据 | 成效显著，投资大幅增长。 | 完成投资1.2亿元，同比增长18%（来源：市统计局月报）。 | 数据+口径+来源 |
| 责任 | 有关部门要高度重视，压实责任。 | 市住建局牵头，各区县政府配合，11月30日前完成整改。 | 主责+时限+动作 |
| 称谓 | 你单位要抓紧办理。 | 请贵单位于11月20日前函复。 | 平行文用"贵单位" |
| 请示结语 | 请领导务必批准！ | 妥否，请批示。 | 期请语气，句号 |
| 通报评价 | 该同志表现非常好。 | 该同志在防汛值守中连续72小时在岗，处置险情3起。 | 事实替代评价 |
| 讲话开场 | 今天我很荣幸…… | 这次会议的主要任务是，部署汛期安全隐患排查。 | 直接点明任务 |
| 方案任务 | 要全力推进各项工作。 | 2026年12月底前完成平台上线；市大数据局负责。 | 任务可衡量、有主责 |

## 二、边界案例

| 情形 | 正确文种 | 理由 |
|---|---|---|
| 向上级申请专项资金，需要批复 | 请示 | 请求批准，且存在隶属关系 |
| 向上级汇报项目进展，不需要批复 | 报告 | 陈述情况，不要求批复 |
| 向不相隶属的兄弟单位申请资料 | 函（请批/商洽函） | 无隶属关系，不能用请示 |
| 面向社会公布交通管制安排 | 通告 | 一定范围内应遵守或周知 |
| 向国内外宣布重要法定事项 | 公告 | 面向国内外、事项重要或法定 |
| 表彰防汛先进集体 | 通报 | 表彰先进属通报适用范围 |
| 部署汛期隐患排查工作 | 通知 | 部署执行属通知适用范围 |
| 记载会议议定事项 | 纪要 | 概括议定事项，不是原始记录 |
| 记录会议每个人发言 | 会议记录（非公文） | 原始记录不属法定文种 |
| 人代会（非常设、集体负责制）通过重大决策事项 | 决议 | 非常设会议 + 重大决策事项集体决断 |
| 中央全会审议通过《关于……的决定》 | 决定 | 常设机关作出，虽经会议通过仍为决定 |
| 机关直接作出行政处分决定 | 决定 | 机关直接作出，非会议表决 |
| 对重要问题提出处理办法 | 意见 | 提供见解与办法，不是具体部署 |
| 印发本单位内部管理办法（非规章） | 通知（印发） | 非规章材料作附件，不直接行文 |
| 公布行政法规、规章 | 命令（令） | 行政法规、规章用命令公布 |

## 三、修改案例

原文：

> 随着汛期来临，我单位高度重视，进一步提高认识，强化措施，压实责任，确保安全度汛。

问题与修改：

| 门禁 | 问题 | 修改 |
|---|---|---|
| G6 | "随着……来临""高度重视""提高认识"为空转与无实指 | 改为具体时间与任务 |
| G5 | 无具体工作安排，段落无推进 | 补主责、时限、动作 |
| G2 | 无数据与来源 | 补水库、堤防数量与来源 |

改后：

> 2026年6月1日进入汛期。全市有水库12座、堤防86公里。各区县于6月10日前完成排查，隐患清单报市应急局；市气象局每日17时前发布预警。

## 四、审核案例

来文片段：

> 关于申请防汛资金的请示
> 发文单位：××区应急管理局
> 市人民政府、市财政局：
> 当前防汛形势严峻，我单位拟申请资金50万元。妥否，请批示。

审核意见：

```
【必须改】G1｜主送栏｜“市人民政府、市财政局”｜违反单一主送｜《条例》第十五条｜保留市政府，市财政局改抄送
【必须改】G2｜第2段｜“资金50万元”｜无来源与测算依据｜补测算表并标注口径
【建议改】G6｜第1段｜“形势严峻”｜无实指｜补雨情、险情或工程缺口数据
【待确认】G1｜主送栏｜“市财政局”｜若与发文单位同级，不属隶属请示｜确认关系；同级则改用函或仅抄送
```

## 五、使用纪律

- 案例是判定参照，不是模板；不得照抄示例内容。
- 争议时先引 `07-review.md` 的门禁与依据，再引本文件案例。
- 案例中的单位、数据均为示例，不得当作真实依据。
- 新案例只从真实修改中提炼，并先去敏。
