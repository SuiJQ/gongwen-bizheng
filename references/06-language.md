# 语言规范与去 AI 味

> 何时读：S3 落笔与即时校验；S4-G6 语言门禁。
> 读完产出：禁用项命中清单、语言修改依据。
> G6 的权威清单见 `07-review.md`；本节为快速自检。取搭配与"平实→有筋骨"提炼对照见 `11-vocab.md`，其可用清单不得越过本节禁用项。

## 一、语体基线

- 准确、简洁、庄重、得体。
- 段落内可先写结论或事项句；全文结构按文种骨架：法定公文一般"缘由—事项—结语"，事务材料"背景—做法—成效/建议"。
- 具体名词、数字、动作优先于抽象判断。
- 动词开句，少用被动。
- 一句一个意思，长句拆分。
- 语气按方向：上行期请、下行指令、平行协商。

## 二、禁用项（硬清单）

| 类别 | 表现 | 处理 |
|---|---|---|
| 空转过渡 | 综上所述、值得一提的是、不难发现、众所周知、由此可见（无新信息） | 删 |
| 万能开场 | "随着……的发展""在……背景下""近年来" | 换具体时间、背景、事项 |
| 排比堆砌 | 为排比而排比，内容空泛 | 删或改具体 |
| 口号堆砌 | 连续"要……要……要……"无具体任务 | 每句落到主责、时限、成果 |
| 无实指判断 | "成效显著""迈上新台阶"无数据 | 补数据或删 |
| 二元套话 | "不仅……而且……"滥用 | 直接陈述 |
| 强行升华 | 结尾上升到时代、人性、历史 | 收束到事项 |
| 修辞问句/感叹号 | 公文中使用反问、感叹 | 改陈述句 |
| 网络用语/口语 | 搞定、拿捏、天花板、干货 | 改书面语 |
| 模糊词 | 近期、日前、若干；责任未定时的"有关部门" | 尽量写具体日期、数量、单位；确实未定时可暂用"有关部门"，但应附确定时限或责任机制 |
| 空责任 | "有关部门要高度重视" | 明确主责单位与动作 |
| 虚假对仗 | 为对称牺牲准确 | 保准确 |

## 三、去 AI 味规则

1. 每个判断后跟事实、数据或场景；跟不出就删。
2. 删除万能开头，直接进入事项。
3. 法定公文用层级序数，不用"首先/其次/最后"机械分段；讲话、发言、情况说明可酌情使用。
4. 句长控制：超过约 50 字考虑拆分（经验值，按语体调整）；一句一个主语。
5. 名词化回退："进行了……的优化"→"优化了……"；"对……进行排查"→"排查……"。
6. 虚词节制：进一步、切实、不断、持续、全面、大力，若无实际含义则删；同段不重复。
7. 数据必须带口径与时间；不写"大幅""明显"而无量化。
8. 同义反复删除：如"重要"与"关键"叠加使用。
9. 修辞节制：比喻、引用仅在确有必要时使用。
10. 结尾收束事项，不强行拔高。

## 四、力度词

| 类别 | 例 | 用法 |
|---|---|---|
| 强制 | 必须、严禁、不得、一律 | 仅用于真强制且能追到依据 |
| 要求 | 要、应、须、需 | 用于任务要求，配主责与时限 |
| 建议 | 可、宜、鼓励、支持 | 用于非强制引导 |
| 期望 | 希望、力争 | 少量，用于号召 |

原则：力度与事项性质匹配；不靠堆词制造力度；同段不重复同义力度词；强制词必须能追到依据。

## 五、称谓与一致性

- 同一文内称谓一致。
- 首次出现用全称，需简称时标注"（以下简称××）"。
- 不混用"我单位/我们/我局/我委"。
- 党委、政府口径不混。
- 人名加职务首次出现，后文按惯例。
- 平行文宜用"贵单位""贵局"，避免"你单位"；"你局"不是命令式称谓，但在平行文中不够得体（惯例）。

## 六、标点与数字

- 标点按 GB/T 15834；数字按 GB/T 15835。
- 标题中除法规、规章名称加书名号外，一般不用标点；顿号、引号、括号等确需时可用；避免句号、感叹号。
- 序数：一、/（一）/1./（1）；不跳级、不混用。
- 统计数字、日期、文号用阿拉伯数字；相邻数字并列连用的概数用汉字，其他概数按 GB/T 15835 处理。
- 数值范围可用"至"、一字线"—"或浪纹号"～"（GB/T 15835 允许）；同一文内统一，避免混用。本技能默认一字线，不判波浪号为错。
- 六角括号〔〕仅用于发文字号年份。
- 附件名称后不加标点。

## 七、句式与段落

- 段首句承担论点或事项。
- 一段一个中心。
- 并列项结构一致（动宾一致）。
- 不写"以下三点"却只列两点。
- 段落 3–8 句为宜（经验值）；过长拆分。

## 八、G6 自检

- [ ] 无空转过渡、万能开场、排比与口号堆砌
- [ ] 段落内 3 个以上搭配且无主责／时限／数据时，已按 `11-vocab.md` 第六节判空转
- [ ] 同段比喻词根不超 2 个（超过即判"油"，见 `11-vocab.md` 第五节）
- [ ] 每个判断有事实、数据或场景支撑
- [ ] 无"成效显著"类无实指表述
- [ ] 称谓一致，党政口径不混
- [ ] 层级序数正确、不跳级
- [ ] 标点、数字、计量单位合规
- [ ] 力度词与事项性质匹配
- [ ] 长句已拆分，被动已改主动
- [ ] 无网络用语、口语缩写
- [ ] 结尾未强行升华

## 九、好差对照

> 示例数据仅示意，不得复用。

| 差 | 好 | 原因 |
|---|---|---|
| 随着经济社会的发展，我单位高度重视，取得了显著成效。 | 2026年前三季度，我单位完成重点项目12个，投资完成率108%（来源：市发改委月报）。 | 换成具体时间、数据与来源 |
| 要进一步提高认识，强化措施，压实责任。 | 各区县于11月30日前完成排查，由市住建局汇总（分工见附件1）。 | 每句落到主责、时限、成果 |
| 不仅提升了效率，而且优化了服务，更重要的是增强了群众获得感。 | 审批时限由10个工作日压缩至3个工作日；群众投诉量同比下降42%。 | 删套话，给可核事实 |

## 十、分文种语体参数（经验值，可按本机关惯例调整）

| 文种 | 目标篇幅（字） | 句长上限 | 数据与事实密度 | 评价句配额 |
|---|---|---|---|---|
| 通知 | 800–1500 | 45 字 | 每千字不少于 6 处时限／责任主体 | 不设总评段 |
| 请示 | 800–1500 | 45 字 | 至少 1 组测算依据或上年实际 | 无评价句 |
| 报告 | 1500–3000 | 50 字 | 每千字不少于 8 组数据 | 总评不超过 1 句，须带数据 |
| 批复 | 300–800 | 40 字 | 引叙来文 1 处（名称＋文号） | 无 |
| 函 | 300–800 | 45 字 | 事项 1–3 项，逐项明确 | 无 |
| 纪要 | 500–1500 | 45 字 | 每项议定事项必带责任与时限 | 无 |
| 总结 | 1500–3000 | 50 字 | 每千字不少于 8 组 | 总评不超过 2 句，须带数据支撑 |
| 讲话 | 800–2500 | 35 字（口语句） | 每千字不少于 4 个事例 | 号召不超过 2 处 |
| 调研报告 | 3000–6000 | 55 字 | 每千字不少于 10 组 | 结论段须与建议一一对应 |
| 方案／规划 | 2000–5000 | 50 字 | 目标须量化，任务须带主责与时限 | 无 |

用法：起草前据文种取一行，作为该篇的"节奏基线"；超限不是硬错，但需在注意事项说明理由（如领导要求压到一页）。

> 说明：本表解决"只有一条 50 字经验值对全部文种通用"的问题。数值为经验区间，不是规范；与 `05-format.md` 的国标参数无关，国标不规定句长与数据密度。

## 十一、压缩取舍优先级（片段与限字删改必读）

同字数削减时按下列顺序**从后往前删**，前四级原则上不删：

| 序 | 内容 | 处理 |
|---|---|---|
| 1 | 主责单位、时限、金额、数量等可核事实 | **保留**，删则转占位并说明 |
| 2 | 政策依据与原文摘录 | **保留**；确需删则降为条款号并注明待核 |
| 3 | 需会议决定或领导签批的事项 | **保留**（删了就不是这份公文了） |
| 4 | 受文方要执行的动作 | **保留**；可压缩表述，不可省略动作 |
| 5 | 过程性叙述（如何研究、如何部署） | 优先压缩为一句 |
| 6 | 背景铺垫、形势分析 | 可删，保留一句定调 |
| 7 | 成效评价、形容词、排比 | 可大幅删 |
| 8 | 重申性内容（与标题或前文重复） | 直接删

**压缩后必做两件事**：① 核对第 1–4 级是否仍有支撑（缺则转 `【待补：…】`）；
② 在注意事项写明「删了什么、为什么可删」，供领导复核取舍。

> 反模式：把 6000 字压到 2500 字时先砍数据、保留排比——这是最常见的压错方向。

## 十二、X 级已否决（看着像套话，但不该改）

第二节的 12 条禁用项全是「一律删/改」。实际写作中有一批写法**长得像套话、其实是公文的正常构成**，按禁用项处理会把稿子改成「账本腔」——只有事项没有判断，读起来比原来的 AI 味更不像人写的。

本节是**否定级**：命中不改，只在需要解释时引用本节说明为何保留。

### 一、不该当套话删的四类

| 写法 | 为什么不是套话 | 保留条件 |
|---|---|---|
| **总评句**（"总的看，上半年任务完成过半""总体平稳、好于预期"） | 机关文稿必然要有判断句，这是领导读稿的落点。它不是"无实指"，而是**对前文事实的概括** | 前文已给出对应事实（数据、进度、问题清单）即可保留；只有**前文无任何事实支撑**时才算空转 |
| **表态句**（"坚决贯彻落实""全力推进"） | 下行文的政治表态是行文规范的一部分，不表态反而不合格 | 出现在段首或结尾的定向表态可保留；**不得作为事项段的主体**（事项段必须是动作＋主责＋时限） |
| **规范性序数列举**（"一是…二是…三是…"／"（一）（二）（三）"） | 这是《条例》与 GB/T 9704 要求的层次结构，不是"AI 爱编号" | 一律保留。序数本身永远不是缺陷，**只有序数后无实质内容才是** |
| **公文惯用结语**（"特此通知""妥否，请批示""以上报告，请审阅"） | 法定格式要求，`03-patterns.md` 按文种规定 | 一律保留，且必须与文种匹配 |

### 二、不该按"AI 指纹"处理的

| 写法 | 为何不改 | 说明 |
|---|---|---|
| 顿号密集并列（"各区县、各部门、各单位"） | 公文规范要求并列项用顿号，密度天然高于其他文体 | 只在**并列项超过 4 项且无层次**时建议分组，不按密度阈值判错 |
| 层次小标题多 | 公文必须有层次标题，`05-format.md` 五节规定四级序数 | 小标题密度不作为缺陷指标 |
| 句长整齐 | 公文语体求庄重，句式相对均匀是文体特征 | 只防**连续三句句法骨架相同**（见 `scripts/check_rhythm.js`），不按 CV 单一阈值判错 |
| 破折号、分号、引号用量 | 公文用量本就极少，单独统计无区分力 | 不做指纹判定 |

### 三、与第二节的关系（必须一起读）

- 第二节判定的是**该写法有没有实指**；本节判定的是**该写法的存在本身是否正当**。
- 冲突时：**先按本节确认"这个写法正当"，再按第二节判断"这一处写得实不实"**。
- 例：「总的看，上半年任务完成过半」——本节确认总评句正当；第二节要求它有前文事实支撑。两者不矛盾：**正当的写法 + 空的内容 = 要改；正当的写法 + 实的内容 = 保留。**

### 四、误改的代价

把总评句、表态句、序数、结语一并删掉，得到的是一份"只有事项、没有判断"的稿子——形式上更"干净"，但领导无法从稿子里看出你觉得情况是好是坏、要往哪个方向走。

> 判断口径：**删掉这句话，读者是否失去"作者的判断"？** 失去就保留；只是失去"作者的措辞"才删。
