# 记忆协议

> 何时读：S0 启动时读取；S6 沉淀时写入。
> 读完产出：任务卡中的记忆命中项；S6 的候选条目或记忆块。

## 一、位置解析顺序

1. 用户明确指定的目录；
2. 环境变量 `GONGWEN_MEMORY_DIR`；
3. 当前可写工作目录下的 `.gongwen/memory/`；
4. 以上都不可写 → 输出记忆块，不停止任务。

**不得把技能包安装目录当作工作区写入**，唯一例外是本包自带的经验库 `experience/`（见 `13-experience.md`，只写做法与判据，不写正文/密级/个人信息）。S0 在任务卡记录本次使用的记忆路径。

```
<工作区>/.gongwen/memory/
├── errors.md    # 错误库
└── style.md     # 风格档案
```

技能包只读；任务期记忆一律写在运行时目录。跨任务的通用经验另存于技能内 `experience/`，两者分工见第十三节。

## 二、S0 加载规则

1. 按上文顺序解析路径；不存在则跳过，不臆造条目。
2. 按文种、场景、错误模式关键词匹配，列出命中条目编号；无命中写"无"。
3. 命中项写入任务卡，只影响警觉点，不改变流程。

## 三、errors.md 模板

```markdown
# 错误库

> 追加为主；合并用 superseded_by 引用，不物理删除；用户要求删除/更正时除外。
> 政策/格式类条目超过 6 个月未复核，标“待复核”。

## E-001 · <一句话错误模式>（YYYY-MM-DD）

- 来源：用户纠正 / 门禁退回 / 自检发现
- 错误表现：<具体写法或做法，附例子>
- 正确形式：<应当怎么写>
- 抑制触发：<什么条件下必须警觉>
- 判定与责任：<G× 门禁；由谁改>
- confidence：高 / 中 / 低
- last_verified：YYYY-MM-DD（政策/格式类必填）
- superseded_by：E-00X（如被合并或替代）
```

示例（通用示例，非用户材料）：

```markdown
## E-001 · 报告结尾使用请示结语（2026-11-15）

- 来源：用户纠正
- 错误表现：报告结尾写“妥否，请批示”
- 正确形式：报告用“特此报告”；需要批准的事项单独行文请示
- 抑制触发：文种=报告，且正文出现请求批准事项
- 判定与责任：G1 文种与行文关系；起草人改
- confidence：高
- last_verified：2026-11-15
```

## 四、style.md 模板

```markdown
# 风格档案

> 追加为主；新旧冲突以最近一次用户明示为准，旧条目保留备查；
> 偏好不得突破合规、事实、格式底线。

## S-001 · <偏好名称>（YYYY-MM-DD）

- 偏好：<具体、可执行>
- 适用场景：<文种/场合>
- 来源：<用户原话或明确指示>
- 不得突破：合规、事实、格式底线
- superseded_by：S-00X（如被替代）
```

## 五、读写时机

| 时机 | 动作 |
|---|---|
| S0 | 解析路径、读取记忆、列命中编号 |
| S6 | 提取候选（≤3 条）、查重、展示、确认、写入 |
| 用户明说"直接记" | 跳过确认，直接写入 |
| 用户要求删除/更正 | 优先执行，记录日期、原因、范围 |

## 六、候选提取规则

应当提取：

- 用户明确纠正过的写法或做法；
- 门禁退回原因，且不是一次性笔误；
- 同类错误出现两次及以上；
- 用户明示、稳定、可执行的风格偏好。

不得提取：正文内容、密级、个人信息、单位敏感数据、一次性细节、猜测。

每次最多 3 条；先查重。

## 七、合并、废止与删除

- **合并**：新增条目，旧条目加 `superseded_by` 并标"已合并"；不物理删除。
- **废止**：标"已废止·日期"，保留备查。
- **删除/更正**：用户明确要求时，允许物理删除或脱敏；在文件末尾记录删除日期、原因、范围。此项优先于"追加为主"。
- **过期**：政策/格式类条目超过 6 个月未复核，标"待复核"，使用前先核对现行规范。

## 八、隐私边界

- 不存公文正文、附件、数据表。
- 不存密级材料、未公开政策、人事与资金敏感信息。
- 不存个人身份信息；只记"做法"与"偏好"，不记"材料"。
- 发现误写敏感信息 → 立即删除并记录。

## 九、无候选记忆

本次没有可复用经验时，明确说明"本次无可沉淀条目"并结束；不写空文件，不强行询问。

## 十、无写权限降级

输出可直接粘贴的记忆块，并说明保存位置：

```markdown
<!-- 追加到 .gongwen/memory/errors.md -->
## E-00X · <错误模式>（YYYY-MM-DD）
- 来源：…
- 错误表现：…
- 正确形式：…
- 抑制触发：…
- 判定与责任：…
- confidence：…

<!-- 追加到 .gongwen/memory/style.md -->
## S-00X · <偏好>（YYYY-MM-DD）
- 偏好：…
- 适用场景：…
- 来源：…
- 不得突破：合规、事实、格式底线
```

## 十一、质量要求

- 条目可判定：审稿人能据此判对错。
- 条目可执行：写清"什么时候做什么"。
- 条目可追溯：带日期、来源与置信度。
- 条目不膨胀：同类合并用引用，不做流水账。

## 十二、主文件记忆协议（v0.3.0 从 SKILL.md 迁入）

> 权威出处：本节即 v0.2.1 主文件第 296–300 行，与前述各节冲突时以前述细则为准。

- 位置解析：用户指定目录 > 环境变量 `GONGWEN_MEMORY_DIR` > 当前可写工作目录下的 `.gongwen/memory/`；不得使用技能包目录。无写权限 → 输出记忆块。
- 文件：`errors.md`（五段式 + confidence + last_verified）、`style.md`（偏好只追加、最近优先、不越底线）。
- 读取：S0；写入：S6；用户确认；每次带日期与来源。
- 删除/更正：用户明确要求时执行，记录日期与原因。
- 禁止：正文、密级、个人信息、一次性细节。

## 十三、与经验库（记忆梦境）的分工

| | 本文件（errors.md／style.md） | `experience/`（记忆梦境） |
|---|---|---|
| 范围 | 本任务的错误与风格偏好 | 跨任务、可复用的判断 |
| 位置 | 工作区 `.gongwen/memory/` | 技能内 `experience/`（唯一允许写的技能内目录） |
| 门槛 | 有来源即可 | 必须过"通用性四问"（见 `13-experience.md`） |
| 用途 | 下次同类任务提高警觉 | 长期抬高能力基线 |

S6 两个都要做：先做记忆梦境定去留，再把任务期错误写入 errors.md。经验库与 references 冲突时以 references 为准。
