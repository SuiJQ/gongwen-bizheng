# 能力降级矩阵（按需读取）

> 由 v0.2.1 主文件第 304–313 行整体迁入。触发条件：出现任一能力缺失时，只读命中的那一行。
> 总原则见主文件「规则卡」第 8 条「能力降级仍要完成」，不得停在半路。
> v0.4.0 增补 2 行（版式工具不可用、用户拒绝版式处理），原 8 行语义未改。

| 缺失能力 | 降级行为 |
|---|---|
| 无法提问 | 输出问题清单 + 骨架 + 假设清单，记"条件通过"，继续 S2 |
| 无法写文件 | 记忆块与交付物直接输出到对话 |
| 无 Node/脚本 | 用 `05-format.md` 勾选表手工核对；占位符人工扫描并记录 |
| 无 DOCX 或无法读取 docx | G4b 记"无法判定·降级"，交付文本 + 版式未核清单 |
| `scripts/format_docx.js` 不可用（旧包、缺文件、Node 版本过低） | 按上一条降级；不得因缺工具中断交付，也不得声称"已排版" |
| `scripts/export_docx.js` 不可用或导出失败 | 只交文本稿并记"DOCX 未生成·版式未核"；不得声称已出 DOCX，也不得改用其他工具绕过占位清零检查 |
| 用户拒绝或未表态版式处理 | 注意事项记"版式未处理（用户选择／未表态）"，G4b 记降级；本轮不再提，不追问 |
| 无 shell | 纯文本运行；不调用脚本 |
| 无网络 | 不引用未核政策；缺依据转占位与待办 |
| 超长文 | 分节 + 已用材料台账 + 断点续写卡 |
| 无提问且门禁二次失败 | 记"升级未遂"，按降级交付并标注风险，不停止 |
